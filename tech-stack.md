# PlannerCapture Technology Stack

## Overview

| Layer | Technology | Version | Purpose |
|---|---|---|---|
| Language | Swift | Toolchain-dependent (`swiftc` local install) | Core application implementation |
| UI | SwiftUI | macOS SDK-provided | Declarative views for popover, planner, and settings UI |
| Windowing/System UI | AppKit (`NSWindow`, `NSPopover`, `NSStatusBar`) | macOS SDK-provided | Menubar app shell, windows, panels, popovers |
| Global Hotkey | Carbon (`RegisterEventHotKey`) | macOS SDK-provided | System-wide `Cmd+Shift+Space` capture trigger |
| Networking | Foundation `URLSession` | macOS SDK-provided | HTTP integration with Daily Helper Hub gateway |
| Notifications | UserNotifications | macOS SDK-provided | Local success/failure user notifications (`CLIWrapper`) |
| Logging | Custom file logger (`PlannerLogger`) | In-repo | Structured app logs and copy-last-error utilities |
| Build Tool | `swiftc` via `build.sh` | Toolchain-dependent | Compiles `Sources/*.swift` into app bundle binary |
| App Packaging | `.app` bundle + generated `Info.plist` | In-repo script generated | Runs as `LSUIElement` menubar-style app |
| Backend dependency | Daily Helper Hub Gateway API | External service | Task/group persistence and sequencing API |
| Data store dependency | Daily Helper Hub DB | External service | Source of truth for tasks/groups |

## Runtime and Build Details

### Build and packaging
- Build script: [`build.sh`](./build.sh).
- Compile command: `swiftc Sources/*.swift -o PlannerCapture.app/Contents/MacOS/PlannerCapture`.
- Bundle metadata source:
  - Generated by `build.sh`, mirrored in [`PlannerCapture.app/Contents/Info.plist`](./PlannerCapture.app/Contents/Info.plist).
  - `CFBundleIdentifier`: `com.user.PlannerCapture`
  - `CFBundleShortVersionString`: `1.0`
  - `LSUIElement`: `true` (runs without Dock app icon as a menubar utility).

### Runtime dependencies
- Hub gateway base URL defaults to `http://127.0.0.1:8765` in [`Sources/SettingsStore.swift`](./Sources/SettingsStore.swift) (`PlannerSettings.default.gatewayURL`).
- API surface consumed in [`Sources/Models.swift`](./Sources/Models.swift):
  - `GET /v1/meta/seq`
  - `GET /v1/tasks?limit=...`
  - `POST /v1/tasks`
  - `PATCH /v1/tasks/{id}`
  - `POST /v1/tasks/{id}/complete`
  - `POST /v1/tasks/{id}/archive`
  - `GET /v1/groups`
  - `POST /v1/groups`
  - `PATCH /v1/groups/{id}`
  - `POST /v1/groups/{id}/archive`

## Configuration and Persistence

### Settings persistence
- Path: `~/Library/Application Support/PlannerCapture/settings.json`.
- Managed by `SettingsStore` in [`Sources/SettingsStore.swift`](./Sources/SettingsStore.swift).
- Includes: gateway URL/token, polling intervals, default status, grouping/sorting modes, UI toggles, diagnostics log level.

### Log persistence
- Path: `~/Library/Logs/PlannerCapture/plannercapture.log`.
- Managed by `PlannerLogger` in [`Sources/PlannerLogger.swift`](./Sources/PlannerLogger.swift).

## Why These Choices Fit This Project

- Swift + AppKit + SwiftUI: practical for a native macOS menubar app requiring popovers, floating non-activating panels, and standard macOS windows.
- Carbon hotkey API: direct way to register reliable global shortcuts in a menubar utility.
- URLSession + JSON decoding in `GatewayClient`: lightweight dependency-free integration with an already existing local gateway.
- File-based settings and logs: simple local persistence with no additional infrastructure in this repo.

## Package Manager, Build, and Infrastructure Notes

- No `Package.swift`, CocoaPods, or third-party dependency manager is used.
- No CI/CD configuration is present in this repository.
- No Docker or deployment manifests are present; this is intended for local macOS execution.

## Known Limitations / Gotchas

- External dependency requirement: app functionality is limited without the Daily Helper Hub gateway + DB process running.
- No API contract pinning/version negotiation beyond endpoint conventions; behavior changes in gateway can break client decoding.
- No automated test harness currently in repo.
- No reproducible pinned Swift toolchain file is present (`swiftc` behavior may vary by installed Xcode/CLI tools version).
